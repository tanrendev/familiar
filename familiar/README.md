# Familiar

Animated pixel companion in the bar: an owl that idles, blinks and hops at
random intervals, with a light and a dark sprite set following the theme mode.

## Plugin

| Field | Value |
| --- | --- |
| ID | `tanren/familiar` |
| Entries | Bar widget: `owl` |

## Usage

Enable `tanren/familiar`, then add the `owl` widget from the Add-widget
picker. It has no settings; the sprite set follows the current theme mode.
